How It Works

  1. Three or more WiFi APs report RSSI.
  2. Log-distance model converts RSSI → distance.
  3. Weighted least-squares trilateration estimates position.
  4. Extended Kalman Filter smooths the estimate over time.
  5. Dijkstra's algorithm finds shortest path on the node graph.
