How It Works

  1. WiFi APs report RSSI → log-distance model → range per AP (metres).
  2. EKF (primary): raw ranges fused via nonlinear measurement model hi(x) = mpp·‖pos − APi‖; Jacobian linearised at each step.
  3. KF (baseline): ranges collapsed to (x, y) by weighted least-squares trilateration, then fused by a linear KF.
  4. Both filters run in parallel; RMSE over a trajectory quantifies the gain from the nonlinear model.
  5. Dijkstra's algorithm finds the shortest path on the node graph.
